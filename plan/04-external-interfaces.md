# Section 04 — External Dependency Interfaces & Mocks

## Overview

Define interfaces for every external system the scheduler talks to. All engines depend on these interfaces (never concrete implementations). Mocks generated by `mockery` enable unit testing without real infrastructure.

## Interfaces

### ClusterAggregator (`pkg/ports/cluster_aggregator.go`)

Aggregates cluster state and vLLM metrics from the fleet.

```go
type ClusterAggregator interface {
    WatchEvents(ctx context.Context) (<-chan model.ClusterEvent, error)
    FullSync(ctx context.Context) ([]model.Cluster, error)
    GetVLLMMetrics(ctx context.Context, appID model.AppID) (model.VLLMMetrics, error)
}
```

- `WatchEvents`: streams cluster events (node/pod state changes). Error on connection failure.
- `FullSync`: returns complete state of all clusters for reconciliation (every 5 min).
- `GetVLLMMetrics`: fetches current vLLM metrics for one app (polled every 10s).

### CacheRegistry (`pkg/ports/cache_registry.go`)

Queries model cache locations across the fleet.

```go
type CacheRegistry interface {
    GetCacheLocations(ctx context.Context, modelID model.ModelID) ([]model.CacheLocation, error)
}
```

### PerformanceProfiler (`pkg/ports/performance_profiler.go`)

Provides profiled performance characteristics for applications.

```go
type PerformanceProfiler interface {
    GetProfile(ctx context.Context, appID model.AppID) (model.PerformanceProfile, error)
}
```

### ClusterClient (`pkg/ports/cluster_client.go`)

Abstracts K8s operations on a specific cluster. Each replica is a single-replica Deployment.

```go
type ClusterClient interface {
    CreateReplica(ctx context.Context, appID model.AppID, constraints model.SchedulingConstraints) (model.ReplicaID, error)
    DeleteReplica(ctx context.Context, replicaID model.ReplicaID) error
    GetReplicaStatus(ctx context.Context, replicaID model.ReplicaID) (model.ReplicaStatus, error)
    LabelReplica(ctx context.Context, replicaID model.ReplicaID, labels map[string]string) error
}
```

### ConfigStore (`pkg/ports/config_store.go`)

Provides application configuration (maps to `model.Application`).

```go
type ConfigStore interface {
    WatchApplications(ctx context.Context) (<-chan model.Application, error)
    ListApplications(ctx context.Context) ([]model.Application, error)
}
```

### LeaderElector (`pkg/ports/leader_elector.go`)

Leader election for HA. No `context.Context` — leader state is observed, not requested.

```go
type LeaderElector interface {
    IsLeader() bool
    OnElected(callback func())
    OnLost(callback func())
}
```

## Supporting Types

### `pkg/model/events.go`

```go
type ClusterEventKind string

const (
    ClusterEventNodeDown       ClusterEventKind = "NodeDown"
    ClusterEventNodeUp         ClusterEventKind = "NodeUp"
    ClusterEventPodTerminated  ClusterEventKind = "PodTerminated"
    ClusterEventPodRunning     ClusterEventKind = "PodRunning"
)

type ClusterEvent struct {
    Kind      ClusterEventKind
    ClusterID ClusterID
    NodeID    NodeID
    ReplicaID ReplicaID
    Timestamp time.Time
}
```

### `pkg/model/constraints.go`

```go
type SchedulingConstraints struct {
    RequiredGPUs        int
    PreferredNodes      []NodeID
    RequiredNodeLabels  map[string]string
    PreferredNodeLabels map[string]string
    CacheAffinityModel  ModelID
}
```

## Mock Generation

- Mockery configured via `.mockery.yaml` at repo root.
- `//go:generate` directives in each port file.
- Mocks generated to `pkg/ports/mocks/`.
